# Bienestar SENA — Demostración pública

Prototipo académico **no oficial**, para presentar la interfaz de Bienestar al Aprendiz.

## Seguridad
- Datos completamente ficticios.
- Sitio estático: solo HTML, CSS y JavaScript del navegador.
- **Sin Supabase, PostgreSQL, API, backend ni credenciales**.
- Registrar, editar y eliminar son simulaciones locales en memoria. Los cambios se reinician al actualizar.
- No introducir datos personales reales.

## Publicación en GitHub Pages
En este repositorio, abrir **Settings → Pages → Build and deployment**; elegir **Deploy from a branch**, rama **main**, carpeta **/(root)** y guardar.

Dirección esperada una vez activado Pages:
https://bryanstevenardilaachury-spec.github.io/demo-publica-/

## Archivos
- index.html: interfaz de demostración
- css/estilos.css: estilos del prototipo
- js/app.js: lógica de simulación sin llamadas externas
